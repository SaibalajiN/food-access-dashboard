# California Food Access & Economic Indicators Dashboard

## Overview
An interactive dashboard analyzing poverty, unemployment, and population trends across California counties using public datasets.

## Key Features
- County-level insights with comparative analysis
- KPIs highlighting poverty rate, unemployment, and population
- Visual storytelling through maps, rankings, and trends
- Designed for clear communication to non-technical stakeholders

## Tech Stack
HTML, JavaScript (Chart.js, D3.js), Public Data (US Census, BLS)

## Live Demo
https://saibalajin.github.io/food-access-dashboard/

## Use Case
Designed to support nonprofit and policy decision-making by identifying high-need regions and highlighting economic patterns across California.
